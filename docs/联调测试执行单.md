## 异常对照

| 现象 | 原因 |
|---|---|
| 网络异常 | 后端没起 / 没勾不校验合法域名 |
| 登录已失效 | token 过期，重新登录 |
| 您不是该会议参会人员 | 账号不在 t_meeting_person，回准备第3步 |
| 通知看不见 | 通知是草稿 / 不在你参加的会议下 |
| 改了 SQL 数据小程序没变化 | 下拉刷新页面或重进（列表页有缓存态的以重进为准） |
